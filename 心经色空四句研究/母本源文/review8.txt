@subtitle ——对《修订执行指令》的处理与新增证据核查

@h1 一、处理结果概述

本轮按三项要求修改：标题减少层级；增加原典证据；改用现代学术汉语，删去半文半白和术语堆砌的写法。《修订执行指令》共列出约六十项意见，逐条核对原典后，多数采纳，五项不采纳或改为另一种处理，理由见第三节。

正式稿：Madhyamaka_Submission.docx，22页，63条脚注。二级标题由25个减为14个，层级改用“一、”“（一）”。

@h1 二、新增证据（均已逐字核对原文）

@table 700,3300,5026 cll
| 号 | 证据 | 在论证中的作用 |
| 1 | 《二万五千颂》Kimura I-2: 159、161–162；Dutt 258.03–06、258.28–259.03：“色空于色……色之不生非色”；“不生非异于色，不生即色，色即不生……所谓‘色’是对不二者的称数” | 经文本身让“非同一”与“反向相即”并存，“即”的内容是“不生”；这是第四节第三小节的主证据 |
| 2 | 罗什译本 T08, no. 223, p. 270c20–23、271a12–19：“色不生是非色”“色不異無生……色即是無生、無生即是色……色入無二法數” | 与证据1对应；句式与《心经》四句全同，只是“空”换成“無生” |
| 3 | 玄奘第二会 T07, no. 220, p. 128a22–29：“色即是無生無滅，無生無滅即是色” | 与证据1对应的另一汉译 |
| 4 | 《大智度论》T25, no. 1509, p. 437a04–09：“色是空，色中無色相”“色性常自無生，非今智慧力故使無生”“如有人破色令空，猶存本色想” | 论师以“空”解释“無生”；同时用于第三节（空性不是使色变空的力量）与第六节（非色灭空） |
| 5 | 法藏《心经略疏》T33, no. 1712, p. 553a19–25：“空亂意菩薩有三種疑……三、疑空是物，取空為有。今明空即色，不可以空取空” | 唐代注家明确以“空即色”防止把空性当作实有之物，与第五节第二小节相互印证 |
| 6 | 真谛译世亲释 T31, no. 1595, p. 190a10、190a21–25 | 世亲释同一句，玄奘译取所空义，真谛译“此色不由真如空故空”取所由义；又直接核实了圆测“梁論第五同世親論”的说法 |
| 7 | 《大乘庄严经论释》ad XI.77（Lévi 1907） | 只把经句配给十种分别而不加解释，核实圆测“莊嚴第五但配經文而不解釋”的说法 |
| 8 | 《大宝积经》T11, no. 310, p. 634a6：“不以空故令諸法空，但法性自空” | 月称所引《宝积经》梵文的汉译对应 |
| 9 | 《瑜伽师地论》T30, no. 1579, p. 541a21–23；《心经幽赞》T33, no. 1710, p. 537a14–17 | 如应者引“雖有一切所言說事，依止彼故諸言說轉”，使第八节的反驳以最强的形式出现 |
| 10 | 《二万五千颂》Kimura I-2: 63：“和合之法无自性，以缘生故” | 经文本身以缘起说明无自性，说明用月称的理证解释此经并非外加 |
@endtable

指令要求核对、但本轮无法取得原文的材料，一律没有写入：无垢友《心经》注藏文及堀内俊郎2018、2022、2023年的研究（论文所在站点被网络代理拦截）；《入中论》第六品第183–186颂（GRETIL 只收第一至五品）；早岛理监修《集论释》对校本。

@h1 三、对指令的批判性处理

@label 采纳
@table 700,4000,4326 cll
| 号 | 指令要点 | 处理 |
| 1 | 第七稿半文半白（“此一”“所同一者”“此举”“方向一致”等） | 全文改写为现代学术汉语；用检索确认这些词已不出现 |
| 2 | “所依个别化”“系属”“锚定”是现代术语负担 | 改为“所空法”“所破”，首次出现时用一句话说明含义 |
| 3 | 摘要写成“文本层／义理层／辩护层”的提纲 | 摘要改为连贯叙述，与正文命题逐句对应 |
| 4 | 不得凭“异名”宣布依缘规定与无自性严格同一 | 第四节第三小节改为：月称以待缘现起说明不以自性生起，又以此说明空性；理由是依缘之生不能是自性之生；肯定性的世俗说明不转归空性 |
| 5 | “两相是所破自性的界说，满足界说而无所有者非所破自性”在定义上自相矛盾 | 此批评成立。改为“名称的转用”：所破的是被设想为事物实有本性的自性（bhāvasvabhāva），法性只是以同一名称称呼诸法的不生，是一种无 |
| 6 | 结论把“空性与缘起的同一”写成肯定内容 | 改为：所肯定的是空性与此色不离，以及空性就是此色的不以自性生起；二者另有经文与月称的根据，不由否定本身确立 |
| 7 | 正面回应“关系本身也是肯定规定”的最强反难 | 第五节第一小节新增一段，区分“否定本身确立的东西”与“关于否定的判断所肯定的东西” |
| 8 | 不空于空性与不在色外并不等值 | 改为：两种读法都不能单独决定空性是否另行成立，不离的直接根据是 nānyatra 一句 |
| 9 | 第三节四种解释的力度要区分 | 写明哪些直接与经文相违、哪些缺乏文本根据、哪些是推理不成立；删去“不生之法不起作用”这一未经证明的推论 |
| 10 | 安慧的三性论证不应在第四节代月称作证 | 移入脚注，并注明不以之代替月称的论证 |
| 11 | 圆测遮诠、商人喻、双重否定之例会让主线分叉 | 均移入脚注 |
| 12 | 删去“全库仅两处”的排他性检索结论 | 删去 |
| 13 | 删去“唯识亦不主张一切施设皆须有真实所指”的过度推论 | 删去 |
| 14 | 表1应表示问答的层次 | 重做为“出发点—第一答至第四答—归结”的层次表 |
| 15 | 汉文原典与作者译文应在字体上分开 | 汉文原典用楷体，作者译文用宋体，梵文用 Times New Roman 斜体，均为五号 |
| 16 | 补法藏、真谛译、《瑜伽师地论》卷四十五 | 均已核对原文后补入，见第二节 |
@endtable

@label 不采纳或改作他种处理
@table 700,3600,4726 cll
| 号 | 指令要点 | 理由 |
| R1 | 将“待于因缘”改译为“有所待”，并补“仆从属于主人不表示仆从不待主人” | 梵文原文是 hetupratyayasāpekṣa，明说“依待因缘”，改译会丢掉“因缘”。正确的处理是保留直译，再指出月称把此岸彼岸、长短也列入“依待因缘”，可见“因缘”不限于能生之因。āyatta 一句的推论此前已三次核对原文，不再引入 |
| R2 | 补入无垢友藏文注与堀内研究 | 指令自身规定“原典与译文必须复核后才能迁入”。本轮无法取得这些原文，按此规定不写入 |
| R3 | 补入《入中论》第六品外空、空空颂 | 同上，无法核读；空空一节改用可核的《中论》第十三品第七、八颂及月称释 |
| R4 | 补入第二十四品“有空”等诸空定义条目 | 已核原文，但与核心论证关系较远，只保留其中“无性自性空”条（以缘起说明无自性）一句 |
| R5 | 字号用 11 磅 | 中文期刊通行五号（10.5 磅）；指令也说明以目标期刊要求为准，暂用五号 |
| R6 | 参考 GitHub 上的审查规范仓库 | 这些仓库本轮没有读取，也不声称已经执行 |
